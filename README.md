# Azot mobi Kino Extension

<img src="https://kcell.sequoia-api.lfstrm.tv/upload/06ff69f71d6bc1b0e0329dffac6067bc.svg" height="100" alt="kcell" />

This extension for [Azot](https://github.com/azot-labs/azot) lets you to download movies, series and shows from the [mobi Kino](https://mobikino.kz/) streaming service.
